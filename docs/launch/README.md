## 一句话介绍

中文：

> 一个 Windows 快捷键弹出的四象限待办小工具，适合临时记录、快速整理和到点提醒。

English:

> A Windows hotkey popup todo app for capturing tasks at your cursor, organizing them by Eisenhower quadrants, and getting reminders.

## 发布前检查

- Release 页面能下载 `QuadrantPopTodo-*.exe`
- README 顶部 GIF 能正常播放
- Issue 模板已经可用
- 发帖文案里的下载链接指向 `/releases/latest`
- 帖子末尾明确邀请用户反馈“快捷键、弹窗位置、提醒体验、SmartScreen 提示”

## 主要卖点

- 按 `Ctrl + Alt + Space` 呼出，窗口贴近鼠标位置
- 四象限整理：重要/紧急
- 每条待办可设置提醒
- 同象限内拖动排序
- 本地 JSON 存储，不需要账号，不上传数据
- 开源，提供 Windows 便携版 exe
