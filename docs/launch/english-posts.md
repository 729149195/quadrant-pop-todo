# English Launch Copy

## Product Hunt

Name:

```text
Quadrant Pop Todo
```

Tagline:

```text
A tiny Windows todo popup for capturing tasks right where your cursor is.
```

Description:

```text
Quadrant Pop Todo is a local-first Windows desktop app for quick task capture. Press Ctrl + Alt + Space, add a task near your cursor, organize it by Eisenhower quadrants, set reminders, and drag-sort priorities without opening a full project management tool.
```

Maker comment:

```text
I built Quadrant Pop Todo because I wanted a faster way to capture small tasks without switching context. The app pops up near the cursor, keeps everything local, and uses the Eisenhower matrix to keep priorities clear.

Current features:
- Windows global hotkey popup
- Eisenhower quadrants
- Per-task reminders
- Drag sorting inside each quadrant
- Local JSON storage, no account required
- Open source with a portable Windows exe

I would love feedback on the popup interaction, reminder flow, and whether custom hotkeys should be the next priority.
```

## Hacker News

Title:

```text
Show HN: Quadrant Pop Todo – a Windows hotkey todo popup with Eisenhower quadrants
```

Body:

```text
I built a small Windows desktop app for quick task capture.

The idea is simple: press Ctrl + Alt + Space, get a popup near your cursor, add a task, and organize it by Eisenhower quadrants. Each task can also have a reminder, and tasks can be drag-sorted inside a quadrant.

It is local-first: no account, no cloud sync, no telemetry. Data is stored as local JSON. The app is open source and the release includes a portable Windows exe.

GitHub:
https://github.com/729149195/quadrant-pop-todo

Download:
https://github.com/729149195/quadrant-pop-todo/releases/latest

I would appreciate feedback from Windows users, especially around hotkey behavior, popup positioning, reminders, and SmartScreen friction for unsigned apps.
```
