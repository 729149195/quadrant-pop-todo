# Social Preview

Use `docs/images/social-preview.png` as the cover image for GitHub, articles, Product Hunt, Reddit, or social posts.

Recommended use:

- GitHub repository social preview
- V2EX / forum post attachment
- Blog or article cover image
- Product Hunt gallery image

GitHub repository social preview currently needs to be set manually in repository settings:

1. Open the repository on GitHub.
2. Go to **Settings**.
3. Find **Social preview**.
4. Upload `docs/images/social-preview.png`.
