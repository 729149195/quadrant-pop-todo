# Changelog

## v0.2.2 - 2026-05-22

- Show todo notes directly on task cards when a note exists.
- Keep empty-note tasks compact while preserving click-to-edit behavior.

## v0.2.1 - 2026-05-22

- Added task reminders with due-time popup, snooze, dismiss, and mark-done actions.
- Added drag sorting inside each quadrant.
- Increased the default window height to show more tasks at once.
- Added resizable window behavior and persisted window dimensions.
- Improved compact task cards, multi-line title display, alignment, spacing, icons, and Apple-style typography.
- Improved tray/window interactions and reduced accidental expand/collapse behavior when using task controls.
- Added GitHub Release workflow for building and publishing the Windows portable exe.
